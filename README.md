# Tyler's Portfolio

A personal portfolio built with GatsbyJS, React, and Bootstrap.

## Quick Start

```bash
npm install
npm run develop
```

## Available Scripts

- `npm run develop` - Start development server (opens browser automatically)
- `npm run build` - Build for production
- `npm run serve` - Preview production build
- `npm run clean` - Clean Gatsby cache
- `npm run deploy:github` - Deploy to GitHub Pages

## Tech Stack

- Gatsby v4
- React 17
- Bootstrap 5
- Sass
